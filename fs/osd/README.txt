Aiphone OSD glyph atlas, generated from Noto Sans CJK SC Regular.
Source: https://github.com/notofonts/noto-cjk
Font copyright: 2014-2021 Adobe (http://www.adobe.com/).
Font license: SIL Open Font License 1.1; see OFL.txt.
Rebuild: python scripts/build-osd-font.py /path/to/NotoSansCJKsc-Regular.otf
Only the fixed status character set is included. Runtime rendering uses Node.js
and FFmpeg raw RGB; it requires no font installation or drawtext filter.
